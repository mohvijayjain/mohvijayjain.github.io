Sentinel-AI: a model that heals itself

Models degrade silently when the world changes. Sentinel-AI closes the loop: detect drift, decide, retrain a challenger, prove it's better, promote it, and explain every step in plain language.

The setup

The served model is a LightGBM regressor predicting NYC yellow-taxi trip duration from 11 features, trained on public NYC TLC trip records. New monthly data is checked against a 7.27M-row reference set, and challengers are judged on a fixed 200,000-row frozen test set.

The self-healing loop

  1. Detect drift, three waysStatistical (PSI, KS, JS, Wasserstein), SHAP drift (change in mean |SHAP| per feature) and prediction drift (output distribution).
  2. Score & decideCombined score = 0.4 · statistical + 0.3 · SHAP + 0.3 · prediction → WAIT, MONITOR, ALERT or RETRAIN (≥ 0.75).
  3. Retrain a challengerTriggered in the background; every run tracked in MLflow.
  4. Four validation gatesMetric (RMSE ≥ 1% better, MAE and R² no worse) · paired bootstrap, 1,000 iterations, 95% CI · segment gate (no airport or top zone more than 10% worse) · recent-data sanity check.
  5. Promote or rejectPass all four and the MLflow "Champion" alias moves; fail any and the champion stays. Every attempt is written to PostgreSQL.
  6. ExplainEach run is indexed into ChromaDB so a RAG assistant can answer "why did this retrain get rejected?" with cited sources.

The 40-second bug

The assistant (NVIDIA Nemotron, top-5 retrieval with a 0.85 cosine-distance cutoff) was returning errors on /chat. The cause: the model's reasoning mode added 1,200–1,800 hidden tokens per answer, pushing responses to 39–46 seconds, past the 25-second timeout. Turning reasoning off for this grounded, retrieval-only task brought answers to about 1–2 seconds. Tests now pin that setting and the bounded timeout-and-retry behaviour.

Engineering decisions

  • A segment gate. A better average can hide a broken JFK or LaGuardia segment; the gate blocks that.
  • Calibrated relevance cutoff. The 0.85 distance threshold came from measured distances: relevant 0.35–0.72, off-topic 0.93–1.04.
  • Safe stop. A stop flag is checked between stages, with a final check before any database write, so a cancelled run saves nothing.
  • Honest outcomes. So far the gates have rejected challengers (347.6 s vs 326.6 s error), which is the system doing its job.

API & deployment

14 FastAPI routes: prediction, model info, monitoring history, drifted features, retraining events, CSV/Parquet upload runs, /chat and Prometheus /metrics. A React + TypeScript dashboard (Recharts, TanStack Query) sits on top. It runs on one AWS EC2 instance with Docker Compose (API, PostgreSQL, MLflow, Caddy): only Caddy is exposed, with automatic HTTPS, and it injects the API key so it never reaches the browser. Around 40 pytest test files cover the pipeline.
